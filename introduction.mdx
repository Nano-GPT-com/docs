## Your first request

Create an [API key](https://nano-gpt.com/api), add [balance](https://nano-gpt.com/balance), and install the official Python SDK with `pip install openai`.
Set `NANOGPT_API_KEY` in your environment. Keep the key on your server, outside source control.

Use the exact SDK base URL `https://api.nano-gpt.com/api/v1`. The SDK appends `/chat/completions`, producing `POST /api/v1/chat/completions`. Do not append that endpoint to `base_url` yourself.

```python
import os
from openai import OpenAI

with OpenAI(
    api_key=os.environ["NANOGPT_API_KEY"],
    base_url="https://api.nano-gpt.com/api/v1",
    timeout=60.0,
    max_retries=0,
) as client:
    response = client.chat.completions.create(
        model="openai/gpt-4o-mini",
        messages=[{"role": "user", "content": "Say hello in one sentence."}],
    )
    print("Request ID:", response._request_id)
    print(response.choices[0].message.content)
```

The request ID helps support find a failed request. Save it with your application logs. For streaming, errors, usage and tool calls, copy the tested [Quickstart](/quickstart) example.

## Explore the API

- [Chat Completions](/api-reference/endpoint/chat-completion): `POST /api/v1/chat/completions`
- [Responses](/api-reference/endpoint/responses): `POST /api/v1/responses`
- [Messages](/api-reference/endpoint/messages): `POST /api/v1/messages`
- [Image generation](/api-reference/image-generation): `POST /api/v1/images/generations`
- [Video generation](/api-reference/video-generation): job submission and polling
- [API Hosts](/api-reference/miscellaneous/api-hosts): direct API host, partner domains and runtime limits
- [Private Mode](/api-reference/miscellaneous/private-mode): local encryption proxy

For selected endpoints, you can also use [Accountless Lightning L402 API Payments](/api-reference/miscellaneous/x402) to receive a payment quote without an account or API key by including `x-x402: true` on the initial unauthenticated quote request. All x402 rails, including XNO, were removed on 2026-11-20; the header and API paths retain historical names for Lightning L402. Check `GET /api/v1/x402/endpoints` for the current supported matrix.
