## Setup

Create an [API key](https://nano-gpt.com/api) and add [balance](https://nano-gpt.com/balance). Install `pip install openai` and set `NANOGPT_API_KEY` in your environment. Never put your key in browser code or source control.

## First, a complete response

The SDK base URL is `https://api.nano-gpt.com/api/v1`. This calls `POST /api/v1/chat/completions`.

```python
import os
from openai import OpenAI

with OpenAI(
    api_key=os.environ["NANOGPT_API_KEY"],
    base_url="https://api.nano-gpt.com/api/v1",
    timeout=60.0,
    max_retries=0,
) as client:
    response = client.chat.completions.create(
        model="openai/gpt-4o-mini",
        messages=[{"role": "user", "content": "Say hello in one sentence."}],
    )
    print("Request ID:", response._request_id)
    print(response.choices[0].message.content)
```

## Then, streaming

This example closes the HTTP connection even if parsing fails or you stop consuming the stream. The timeout bounds network operations, including time waiting for another chunk; it is not a total generation deadline.

```python
import json
import os
import sys
from openai import APIError, APIStatusError, OpenAI

# No automatic retries: retrying an interrupted generation can create a new charge.
with OpenAI(
    api_key=os.environ["NANOGPT_API_KEY"],
    base_url="https://api.nano-gpt.com/api/v1",
    timeout=60.0,
    max_retries=0,
) as client:
    try:
        with client.chat.completions.with_streaming_response.create(
            model="openai/gpt-4o-mini",
            messages=[{"role": "user", "content": "Say hello in one sentence."}],
            stream=True,
            stream_options={"include_usage": True},
        ) as response:
            print("Request ID:", response.headers.get("x-request-id", "not supplied"))
            tools = {}
            for chunk in response.parse():
                if chunk.usage:
                    print("Usage:", chunk.usage.model_dump(), file=sys.stderr)
                # Usage-only frames can have no choices; never assume choices[0].
                for choice in chunk.choices or []:
                    delta = choice.delta
                    reasoning = getattr(delta, "reasoning_content", None) or getattr(delta, "reasoning", None)
                    if reasoning:
                        print(reasoning, end="", file=sys.stderr, flush=True)
                    if delta.content:
                        print(delta.content, end="", flush=True)
                    for part in delta.tool_calls or []:
                        key = (choice.index, part.index)
                        tool = tools.setdefault(key, {"id": "", "name": "", "arguments": ""})
                        if part.id:
                            tool["id"] = part.id
                        if part.function:
                            tool["name"] += part.function.name or ""
                            tool["arguments"] += part.function.arguments or ""
            print()
            # Inspect completed calls; validate names/arguments before executing anything.
            for tool in tools.values():
                print("Tool call:", json.dumps(tool), file=sys.stderr)
    except APIStatusError as error:
        print("Request ID:", error.request_id, file=sys.stderr)
        print("HTTP error:", error.status_code, error.response.text, file=sys.stderr)
        raise
    except APIError as error:
        # Includes in-stream error frames and connection/time-out failures.
        print("Generation failed:", error, file=sys.stderr)
        raise
```

The SDK parses SSE and raises for HTTP and in-stream error frames. Usage-only frames, empty deltas, reasoning and fragmented tool calls are handled separately. Reasoning and tool support depend on the selected model; this prompt does not request tools. The tool-call collector shows how to handle models that emit them; it never executes a tool.

Keep the request ID printed before streaming when reporting an interrupted request. HTTP failures show the status, response body and request ID; avoid exposing raw error bodies or reasoning in public logs. A timeout or interrupted stream does not prove the request was unbilled. Inspect the failure before retrying; honor `Retry-After` on rate limits, and do not retry authentication or validation failures without correcting the request.
