# Using Cline with NanoGPT

A quick guide to setting up Cline with NanoGPT's API.

## Setup Instructions

1. Get your API key from [nano-gpt.com/api](https://nano-gpt.com/api)
2. In Cline settings, add a new Custom Model with these details:
   - API Provider: OpenAI Compatible
   - Base URL: https://api.nano-gpt.com/api/v1/
   - API Key: Your key from step 1
   - Model ID: {exampleTextModel}

> **Tip:** If Cline is not showing a model's `thinking` output, switch the Base URL to `https://api.nano-gpt.com/api/v1legacy/`. Cline still expects the legacy streaming shape for parallel thinking/output channels, and this endpoint keeps that compatibility without affecting model availability. It only changes the response shape; it doesn't turn reasoning on for a model.

## Subscribers

With the Base URL above, Cline lists every NanoGPT model, including models your subscription doesn't cover. To see only the models your subscription includes, use `https://api.nano-gpt.com/api/subscription/v1/` as the Base URL instead: Cline then loads its model list from [`/api/subscription/v1/models`](/api-reference/endpoint/models). The subscription Base URL has no `v1legacy` variant, so the thinking tip above doesn't apply to it. To keep a key from ever billing your balance, set its billing mode to **Subscription only** (see [API key billing settings](/api-reference/miscellaneous/billing-override#api-key-billing-settings)); requests your subscription doesn't cover are then rejected instead of charged.

That's it! You can now use Cline with every model you can think of. Model names are on our [pricing page](https://nano-gpt.com/pricing) - important ones are {exampleTextModel}, anthropic/claude-opus-5.5, google/gemini-flash-latest, or just any other model you fancy.
