# JavaScript SDK

`@nanogpt/sdk` is NanoGPT's official client and works from plain JavaScript. It is ESM-only and needs Node.js 22 or later, or another runtime with Fetch and Web Streams.

```bash
npm install @nanogpt/sdk
```

```javascript
import { NanoGPT } from '@nanogpt/sdk';

const client = new NanoGPT({ apiKey: process.env.NANOGPT_API_KEY });

const completion = await client.chat.completions.create({
  model: '{{example-text-model}}',
  messages: [{ role: 'user', content: 'Say hello in one sentence.' }],
});

console.log(completion.choices[0]?.message?.content);
```

Save this as a `.mjs` file, or set `"type": "module"` in your `package.json`.

See the [TypeScript SDK](/api-reference/miscellaneous/typescript) page for the full list of methods, streaming and error handling.

## Other packages

`nanogptjs`, `nanogpt-client` and the npm package named `nanogpt` aren't published or reviewed by NanoGPT. They would receive your API key, so check them yourself before using them.
