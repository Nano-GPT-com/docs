## Overview

Serves a finished video (or a Sora 2 thumbnail or spritesheet) that NanoGPT stores. You normally don't build these URLs: the status endpoints return them.

### Access

A status response signs these URLs (`expires`, `sig`) when it is read by the account that created the job, for a job paid anonymously with x402, or through a `statusUrl`; a signed URL works without an API key for 24 hours. An older job read by its ID alone gets unsigned URLs. Without a valid signature, only the account that created the job can fetch it, with its API key (`x-api-key`) or session; anyone else gets `404`, as for a job that doesn't exist. Poll the status endpoint again for a fresh signed URL.

### Endpoint
```
GET /api/generate-video/content
```

### Query parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `runId` | string | Yes | The job ID (`vid_...`) or provider run ID, as in the URL a status response returned |
| `model` | string | Yes | The model, as in that URL |
| `variant` | string | No | `video` (default); for Sora 2 also `thumbnail` or `spritesheet` |
| `expires`, `sig` | string | No | The signature a status response added; good for 24 hours |

## Usage

```bash
curl -s "https://api.nano-gpt.com/api/generate-video/content?runId=RUN_ID&model=sora-2&variant=video" \
  -H "x-api-key: YOUR_API_KEY" | jq .
```
